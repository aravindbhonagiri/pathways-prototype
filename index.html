Design principle: Assessment is the primary signal. Teacher observations and student feedback can refine or override recommendations. A learner can need remediation in one topic and enrichment in another.
Product logic

Small MVP. Clear learning loop.

The first version tests whether mastery-led recommendations can support different learning needs using existing content and teacher oversight.

①

Assess

Use short, concept-aligned checks and define a mastery threshold before launch.

②

Recommend

Below threshold: remediation. At/above threshold: enrichment or the next learning step. Unclear result: teacher review.

③

Learn and iterate

Track mastery, meaningful engagement, recommendation quality, teacher effort and stakeholder feedback.

What is included in this prototype?

Intentionally limited to the agreed MVP.

✓ Included

Learner journeys, short mastery checks, rule-based recommendations, activity previews, teacher review actions and lightweight feedback selection.

↗ Deferred

Interactive AI avatar, AI-generated content, automated teacher incentives, full parent portal, production data integrations and validated learning-effectiveness claims.

Important: This is a front-end concept prototype with illustrative questions, content and teacher records. It does not use real student data, connect to school systems, or establish that the approach improves learning. Those questions belong in the proposed feasibility pilot and controlled impact study.
